# Arastirma
Proje Adı: Günümüz İnternetindeki bilgi kirliliğinin insana etkileri.
Konusu: Genç kitlenin iletişimi içerisinde günlük olarak kullandığı teknoloji hakkında yeterince bilgi sahibi olup olmadığımızı yorumlamak.
Kullanılacak veri seti: Literatür araştırması dışında bir anket yapmayı planlıyorum.
Yöntem: Anket ile 20-28 yaş arası kitlenin günlük hayatta internette olan biteni sorgulama miktarını incelemeyi planlıyorum. Bunu 3 aşamada yapacağım:
1-Genel bilgi:
Bu kısımda kişinin internet ile ilgili genel anlamda bilgisi sorgulanmakta.
2-Bilgiye ulaşım:
Bu kısımda kişinin interneti nasıl kullancığı yorumlanmakta.
3-İnternetteki bilgi kirliliğinin gözlemi:
Bu kısımda kişinin bilgi kirliliği hakkında farkındalığı incelenmekte.
bu 3 kısımdan yeterli çıkarımın yapılabileceğini düşünüyorum.
